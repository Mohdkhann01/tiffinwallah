Tiffin-Wallah homepage background videos
=======================================

The homepage is configured to rotate between two local MP4 files. Save the clips below into this folder using the exact filenames shown:

1. food-preparation.mp4 — Indian food preparation / hands preparing Indian dishes
   Source: https://www.pexels.com/video/person-preparing-a-food-8811070/

2. professional-kitchen.mp4 — professional kitchen / chefs preparing meals
   Source: https://mixkit.co/free-stock-video/kitchen/

Download clips from the source pages and check the license for the specific clip before using it commercially. Keep them in MP4 (H.264) format; landscape 16:9 is recommended.

The page already handles autoplay (muted), looping, crossfading between the two videos, mobile sizing, and fallback to the existing food image if a video file is missing or cannot load. Do not change the filenames unless you also update client/src/App.jsx.
